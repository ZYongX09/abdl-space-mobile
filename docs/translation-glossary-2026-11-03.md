# App翻译词库管理（开发线，2026-11-03）

本轮在App管理的统一AI/帖子翻译策略旁增加词库管理，不另设模型或密钥。用户可新增、编辑、删除和搜索条目；中文与英文各支持多条同义词，每行一个，可附可选备注。所有内容按纯文本显示，不把术语或备注当HTML。

## 使用与合同

管理员加载后编辑词库，明确点击保存；取消或重新加载丢弃未保存内容前有确认。revision冲突保留草稿、禁止盲重试，账号或角色改变会丢弃旧异步结果并拒绝继续保存。

`GET/PUT /api/admin/app-ai/translation-glossary`：GET为`{entries:[{id,chinese:[],english:[],note}],revision}`，PUT精确`{entries,revision}`；管理员JWT/OAuth、可信Origin、CAS、审计与no-store由后端保证。最多200条、每语言1–10个变体、单变体120码点、备注500码点，trim/NFC规范化、英文忽略大小写去重，跨条同语言重复拒绝；规范entries UTF-8 JSON≤64KiB，请求≤96KiB。后端校验为权威。

保存会显式递增后端共享译文缓存世代，后续请求可能重新生成译文并消耗发起者额度；不自动重译已显示内容，不清日账本，也不自动重发旧结果未知任务。词库保存成功后的内存事件让无草稿策略卡重新载入元数据；已有策略草稿保持并要求明确重载，避免自动覆盖或以旧revision提交。缓存世代只能保持或增加，不能倒退复活旧词库译文。
